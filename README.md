# Cat Notes Android

A native Android note-taking application for creating, managing, and organizing personal notes. It integrates with the shared Cat Notes backend API to provide note management and account synchronization across web, Android, and iOS platforms.

## Features

- **Note Management:** Create, view, edit, and delete notes.
- **Secure Notes:** Create and manage private notes with additional security features.
- **User Authentication:** Account authentication and user access management.
- **Backend API Integration:** Communicate with the Cat Notes REST API for note management and data synchronization.
- **Custom Fonts:** Support custom fonts for personalized reading and writing experiences.
- **Multilingual Support:** English, Simplified Chinese, and Traditional Chinese interfaces.
- **Note Editing:** Rich note editing experience with additional editing functionality.
- **Data Management:** Retrieve and manage notes through backend services.

## Technologies

- Kotlin
- Java
- Android SDK
- Retrofit
- Gson
- Clerk
- SQLite
- REST APIs
- Gradle

## Technical Highlights

- Developed a native Android application using Java.
- Integrated Retrofit and Gson for REST API communication and JSON serialization.
- Implemented user authentication using Clerk.
- Integrated with a shared backend API used by the web and iOS applications.
- Implemented note management and secure note functionality.
- Supported custom font loading and multilingual application resources.

## Requirements

- Android 8.0 (API 26) or later.
